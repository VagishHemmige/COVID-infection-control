Differences from the original code

Author

Vagish Hemmige

This page lists every way the scripts on this site differ from the original analysis: a single R Markdown file of March 2021 (Mayar_R_markdown_2021-3-1.Rmd), which produced the figures and model results of the published article (Al Mohajer et al. 2021). The original file is kept outside this repository.

Each entry is one of five kinds:

  • Corrected: a mistake in the original code, corrected here.
  • Same result: the code is written differently, and gives the same numbers and figures.
  • Added: something the original code did not do.
  • Removed: something the original code did that is no longer needed.
  • Kept: something in the original code that looks unusual, kept as it was so the code still matches what was published.

No entry changes the models, the weekly estimates or the published results; the one correction changes a legend label.

NoteStatus

The scripts have been checked by reading; they have not yet been run on the study data. “Same result” means the code is written to give the same numbers and figures as the original; that is to be confirmed on the first run.
