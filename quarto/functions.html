Weekly estimates with exact intervals

add_exact_intervals()

For each week, the percentage of healthcare-personnel tests that were positive, and the HAI rate per 1,000 patient-days, each with a 95% confidence interval (analysis plan, section 8.1).

Both intervals are exact: they come from the binomial and Poisson distributions themselves rather than a normal approximation. This matters for the HAI series: the article reports weekly HAI counts rising from 0 to 7 before face shields and falling to 0 after them (Al Mohajer et al. 2021). With so few events a normal approximation can give a lower bound below zero, while an exact interval for a week with no infections still runs from 0 to a sensible upper bound. binom.exact() gives the Clopper–Pearson interval and pois.exact() the exact Poisson interval, with patient-days as the exposure.

The original code computed the same intervals and attached them with cbind(); here they are added as named columns with mutate(), which makes clear what each column is. Either way, each value is matched to its week by position: binom.exact() and pois.exact() return one row per input row, in the same order, so the weekly table must not be reordered or filtered between computing the intervals and adding them. The function does both in one step, so nothing can come between them.

Used in the analysis: Data: weekly estimates.

# Adds the weekly estimates of analysis-plan.md section 8.1: the percentage
# of healthcare-personnel tests positive, with an exact binomial interval,
# and the HAI rate, with an exact Poisson interval using patient-days as the
# exposure. `weekly` has one row per week with the columns Positives, Tested,
# HAI and Ptdays.
add_exact_intervals <- function(weekly, conf_level, rate_per) {
  positivity <- binom.exact(
    weekly$Positives,
    weekly$Tested,
    conf.level = conf_level
  )
  hai <- pois.exact(
    weekly$HAI,
    weekly$Ptdays,
    conf.level = conf_level
  )

  weekly |>
    mutate(
      percent_positive = 100 * positivity$proportion,
      percent_lower = 100 * positivity$lower,
      percent_upper = 100 * positivity$upper,
      hai_rate = rate_per * hai$rate,
      hai_rate_lower = rate_per * hai$lower,
      hai_rate_upper = rate_per * hai$upper
    )
}

The fitted line

build_fitted_line()

The predicted value of a fitted model for every week, for drawing its line on a plot. At the intervention the published model jumps: it predicts one value at week 13 without the intervention and another with it. To draw that jump, the function includes the break twice, once on each side, so the line rises to the pre-intervention prediction and drops straight down to the post-intervention one.

The original code did this by adding two placeholder rows to the data at week 12.9999, which then had to be ignored by the models. Building the line separately keeps the data as they are.

For the HAI models, the prediction is made with Ptdays set to 1, so the model returns a rate per patient-day, which scale turns into a rate per 1,000.

Used in the analysis: Models: fitted lines.

# Predicted values from a fitted model for every week, for drawing its line.
# The week just before the intervention week appears twice, once without and
# once with the intervention, so the line shows the jump at the intervention.
# `scale` turns the prediction into the plotted unit: 100 for a percentage
# from a logistic model, or the rate denominator (1,000) for a Poisson model,
# whose prediction is per patient-day because Ptdays is set to 1.
build_fitted_line <- function(model, first_week, last_week, intervention_week, scale) {
  break_week <- intervention_week - 1e-4

  before <- tibble(
    Week = c(first_week:(intervention_week - 1), break_week),
    Intervention = FALSE
  )
  after <- tibble(
    Week = c(break_week, intervention_week:last_week),
    Intervention = TRUE
  )

  bind_rows(before, after) |>
    mutate(
      Week2 = Week - intervention_week,
      Ptdays = 1,
      fitted_value = scale * predict(model, newdata = pick(everything()), type = "response")
    )
}

Values at the intervention week

predict_at_intervention_week()

The article reports, for each outcome, what the published model predicts at week 13 without face shields and with them, and whether the two differ. Because the models centre week at 13 (Week2 is zero there), the Intervention coefficient is exactly that difference, on the log-odds or log-rate scale, and its P value is the test the article reports. The function returns the two predicted values and that P value.

The original code did not compute these values; it printed the model summaries, from which they were read.

Used in the analysis: Models: values at week 13.

Click to show/hide R Code 
# The paper's headline contrast (analysis-plan.md section 8.2): the predicted
# value in the intervention week without and with the intervention, and the
# P value of the intervention term. The models centre week at the
# intervention week (Week2 = 0), so the intervention term is that contrast.
predict_at_intervention_week <- function(model, scale) {
  tibble(
    Week2 = 0,
    Intervention = c(FALSE, TRUE),
    Ptdays = 1
  ) |>
    mutate(
      scenario = if_else(Intervention, "With face shields", "Without face shields"),
      predicted = scale * predict(model, newdata = pick(everything()), type = "response"),
      p_value = coef(summary(model))["InterventionTRUE", "Pr(>|z|)"]
    ) |>
    select(scenario, predicted, p_value)
}

Plotting a weekly series

plot_weekly_series()

Every week-based plot in the analysis has the same parts: a point for each week, sized by how many tests or patient-days it contributed; its 95% interval; a red line at the intervention; and, for a model plot, the model’s fitted line in blue. The original code wrote out a full ggplot() call for each of its ten plots; here one function draws them all, and the plots differ only in what they are given.

Columns are passed unquoted (for example y = percent_positive); the function uses { } to pass them on to {ggplot2}.

Used in the analysis: Figures.

# One weekly series as in Figure 1: points sized by tests or patient-days,
# 95% intervals, a red line between the last week before and the first week
# with the intervention, and, when `fitted` is given, a model's fitted line in
# blue. Columns are passed unquoted, for example y = percent_positive.
plot_weekly_series <- function(weekly,
                               y,
                               lower,
                               upper,
                               size,
                               y_label,
                               size_label,
                               line_week,
                               week_breaks,
                               week_labels,
                               size_range,
                               fitted = NULL,
                               x_label = "Week") {
  weekly_plot <- ggplot(weekly) +
    geom_point(aes(x = Week, y = {{ y }}, size = {{ size }})) +
    geom_errorbar(
      aes(x = Week, ymin = {{ lower }}, ymax = {{ upper }}),
      width = 0.2
    ) +
    geom_vline(xintercept = line_week, color = "red") +
    scale_x_continuous(
      breaks = week_breaks,
      labels = week_labels,
      minor_breaks = NULL
    ) +
    scale_size(range = size_range) +
    labs(x = x_label, y = y_label, size = size_label) +
    theme_light() +
    theme(
      axis.text.x = element_text(angle = 45, hjust = 1, size = 6),
      axis.title.y = element_text(size = 10),
      legend.justification = c(0, 0.5)
    )

  # geom_path() draws the fitted values in the order given, so the two points
  # at the break week join as a vertical step
  if (!is.null(fitted)) {
    weekly_plot <- weekly_plot +
      geom_path(data = fitted, aes(x = Week, y = fitted_value), color = "blue")
  }

  weekly_plot
}
