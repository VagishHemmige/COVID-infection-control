This script fits the interrupted time series models, for both outcomes, and builds what the tables and figures need from them.

The original analysis fitted four models for each outcome, each adding to the one before. Only the fourth, the segmented regression model, was reported in the article; the other three were exploratory, and show why the fourth was needed. They are kept here for that reason and labelled exploratory wherever they appear (analysis plan, section 8.3).

The four models

Each model is written once, as the right-hand side of its formula, and used for both outcomes:

Model Terms What it assumes
its1_week (exploratory) Week One steady trend over the whole period; the intervention changes nothing
its2_intervention (exploratory) Intervention A different level before and after, with no trend over time
its3_level_change (exploratory) Intervention + Week One trend, with a jump in level at the intervention
its4_segmented (published) Intervention * Week2 A jump in level at the intervention and a change in the trend

The fourth model is segmented regression, the standard model for an interrupted time series. Intervention * Week2 expands to three terms: the trend before the intervention (Week2), the jump at week 13 (Intervention), and the change in trend after it (Intervention:Week2). The earlier models are simplifications of it, each leaving out one or more of these terms.

Click to show/hide R Code 
# The right-hand side of each model (analysis-plan.md sections 8.2 and 8.3).
# its4_segmented is the model reported in the article; the other three are
# exploratory and were not reported. Week2 is the week centred at the
# intervention week, so in its4_segmented the Intervention term is the
# contrast at week 13 and the interaction term is the change in slope.
model_terms <- c(
  its1_week = "Week",
  its2_intervention = "Intervention",
  its3_level_change = "Intervention + Week",
  its4_segmented = "Intervention * Week2"
)

Test positivity

Logistic regression of the positive tests out of all tests in each week. cbind(Positives, Tested - Positives) gives the model the numbers of positive and negative tests, so each week counts in proportion to how many tests it had: a week with many tests carries more weight than a week with few.

Click to show/hide R Code 
# Logistic regression of positive healthcare-personnel tests out of tests
# performed
positivity_models <- map(model_terms, \(terms) {
  glm(
    as.formula(str_c("cbind(Positives, Tested - Positives) ~ ", terms)),
    family = binomial,
    data = weekly
  )
})

Hospital-acquired infections

Poisson regression of the number of HAIs each week. The number of inpatients varies from week to week, so the count is modelled relative to patient-days through an offset: log(Ptdays) enters the model with its coefficient fixed at 1, which makes the model one for the rate of HAIs per patient-day.

Click to show/hide R Code 
# Poisson regression of weekly HAI counts, with log patient-days as an offset
hai_models <- map(model_terms, \(terms) {
  glm(
    as.formula(str_c("HAI ~ ", terms)),
    offset = log(Ptdays),
    family = poisson(link = "log"),
    data = weekly
  )
})

Model tables

tbl_regression(exponentiate = TRUE) turns each model’s coefficients into odds ratios (positivity) or incidence rate ratios (HAI), with 95% confidence intervals and P values.

For the published model, the ratios read as follows:

  • Week2: the change from one week to the next before the intervention.
  • Intervention: the jump at week 13, from the value the pre-intervention trend predicts to the value with the intervention.
  • Intervention:Week2: how much the week-to-week change after the intervention differs from the change before it. A ratio below 1 means the trend bent downwards.

The confidence intervals in these tables are profile-likelihood intervals, which is what confint() gives for these models. The P values are Wald tests.

Click to show/hide R Code 
# Odds ratios (positivity) and incidence rate ratios (HAI), as in the
# original code. In its4_segmented, the Week2 ratio compares each week with
# the one before it before the intervention, and the interaction ratio
# compares that week-to-week change after the intervention with the change
# before it.
positivity_tables <- map(positivity_models, tbl_regression, exponentiate = TRUE)
hai_tables <- map(hai_models, tbl_regression, exponentiate = TRUE)

Fitted lines

For each model, its predicted value for every week, for drawing on the figures, from build_fitted_line(). Positivity is shown as a percentage, so its predictions are multiplied by 100; HAI rates are per 1,000 patient-days.

first_week <- min(weekly$Week)
last_week <- max(weekly$Week)

positivity_fitted <- map(
  positivity_models,
  build_fitted_line,
  first_week = first_week,
  last_week = last_week,
  intervention_week = intervention_week,
  scale = 100
)
hai_fitted <- map(
  hai_models,
  build_fitted_line,
  first_week = first_week,
  last_week = last_week,
  intervention_week = intervention_week,
  scale = hai_rate_per
)

The article also reports the P value of the change in slope, which is the Intervention:Week2 row of the model table.
