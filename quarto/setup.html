This script attaches every package the analysis uses and defines every value a reader might want to change. The other scripts never call library() or type a number that belongs here: the intervention week, for example, is set once and used by the models, the fitted lines and both figures.

The full R script is available at:

  • R/setup.R

The code sections below are imported directly from that script when this page is rendered.

Packages

readxl reads the weekly surveillance workbook, epitools computes the exact confidence intervals for each week, gtsummary turns the fitted models into tables of odds ratios and rate ratios, and cowplot stacks the two panels of Figure 2. The tidyverse provides the data handling (dplyr), reading the Harris County file (readr) and the plots (ggplot2).

The original R Markdown file also loaded reshape2, svglite, flextable, knitr and ggthemr, and loaded dplyr and ggplot2 twice. None of these is needed by the analysis, and ggthemr is not on CRAN, so they are not loaded here.

Click to show/hide R Code 
library(tidyverse)  # dplyr, readr, stringr, ggplot2
library(readxl)     # the weekly surveillance workbook
library(epitools)   # exact binomial and Poisson confidence intervals
library(gtsummary)  # model tables
library(cowplot)    # Figure 2: two panels stacked

Where the data are

The data are not in this repository. The person running the analysis puts the folder that holds them in COVID_IC_DATA_DIR, in their .Renviron file, and the scripts find both files there. The original code expected the files in the working directory, with a reminder to set it (#setwd here).

Click to show/hide R Code 
data_dir <- Sys.getenv("COVID_IC_DATA_DIR")
surveillance_file <- "Surveillance manuscript2 9-19.xlsx"
harris_file <- "Harris_data.csv"

Study dates

These implement section 6 of the analysis plan. Week 1 begins on Friday 17 April 2020, when surveillance testing started; later weeks begin on Mondays. Face shields were required from Monday 6 July 2020, the first day of week 13, so intervention_week is 13. Every other part of the code that depends on the timing of the intervention takes it from here.

Click to show/hide R Code 
# analysis-plan.md section 6. Week 1 begins on Friday 17 April 2020; weeks 2
# onward begin on Mondays. Week 13, beginning 6 July 2020, is the first week
# with universal face shields.
study_start <- as.Date("2020-04-17")
intervention_start <- as.Date("2020-07-06")
study_end <- as.Date("2020-09-07")
intervention_week <- 13

Week labels

The figures label weeks 2 to 22 by the Monday each begins. The original code typed the 21 labels out by hand in each of its ten plots; here they are computed once from the first Monday, 20 April 2020.

Click to show/hide R Code 
# Axis labels for weeks 2 to 22: the Monday each week begins
labelled_weeks <- 2:22
week_label_dates <- seq(
  as.Date("2020-04-20"),
  by = "week",
  length.out = length(labelled_weeks)
)
week_labels <- str_c(
  format(week_label_dates, "%b"),
  " ",
  as.integer(format(week_label_dates, "%d"))
)

Estimation constants

Weekly intervals are 95% intervals, and hospital-acquired infection (HAI) rates are expressed per 1,000 patient-days (analysis plan, section 8.1).

Click to show/hide R Code 
# analysis-plan.md section 8.1
confidence_level <- 0.95
hai_rate_per <- 1000  # HAI rate per 1,000 patient-days

Plot constants

The red line marking the intervention falls halfway between week 12 and week 13. Point sizes, which show how many tests or patient-days each week contributed, range from 1 to 3.

Figure 2 draws daily Harris County cases on a second axis. ggplot2 allows a second axis only as a transformation of the first, so the cases are divided by a scale factor to share the left axis, and the second axis multiplies them back. The factors are kept exactly as in the original code.

Click to show/hide R Code 
# The vertical line falls between the last week before the intervention and
# the first week with it
intervention_line_week <- intervention_week - 0.5
point_size_range <- c(1, 3)

# Figure 2 puts daily Harris County cases on a second y-axis. The original
# code scaled the cases by 3780 / 22 for the positivity panel and 3780 / 7 for
# the HAI panel; the same factors are kept here.
harris_scale_positivity <- round(3780 / 22)
harris_scale_hai <- round(3780 / 7)
